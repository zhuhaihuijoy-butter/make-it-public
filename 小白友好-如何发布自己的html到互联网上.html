Two words first

先搞懂两个
基本概念

不用背术语，理解就好 :)
01Deployment

部署

把电脑里的 HTML、CSS、JS 和图片，放到一台能被互联网访问的服务器上。做完这一步，你的网站才算真正“开张”。

📦 类比：把作品从书桌搬进临街店铺
02Domain

域名

网站的地址，也可以理解为互联网上的“门牌号”。别人输入它，就能准确找到你的网站。

📍 类比：让朋友找到店铺的导航地址
Top-level domain

域名后缀，
其实有很多选择

同一个网站可以拥有不同后缀。它们主要区别在品牌观感、价格、注册规则和熟悉程度，不是功能强弱。

mywebsite.commywebsite.aimywebsite.sitemywebsite.xyzmywebsite.iomywebsite.cnmywebsite.commywebsite.aimywebsite.sitemywebsite.xyzmywebsite.iomywebsite.cn

.com > .ai > .io
> .site / .xyz

给 AI 产品或个人网站的实用排序： .com 最容易获得普通用户信任；.ai 适合 AI 项目但通常更贵；.io 更像科技创业公司；.site 和 .xyz 便宜好注册，但品牌感相对弱。

Netlify 拖拽上传

app.netlify.com ↗
01

打开 Netlify
注册或登录账号，进入项目页面。

把整个项目文件夹拖进去
不要只拖一张图片；首页通常需要命名为 index.html。

等待生成公开网址
部署完成后，复制 netlify.app 地址发给朋友。

好处：操作最简单，速度最快，几乎没有代码门槛。
示例：waiwai-learn-obsidian.netlify.app

GitHub Pages

github.com ↗
02

新建 Repository
在 GitHub 右上角点击 “+”，创建一个仓库。

上传网页文件
把 HTML、CSS、JS 和图片完整放进仓库。

开启 Pages
进入 Settings → Pages，选择从 main 分支发布。

得到公开地址
通常格式为 USERNAME.github.io/REPOSITORY。

好处：本地改完代码再 push，网站就能持续更新，很适合长期维护。
示例：zhuhaihuijoy-butter.github.io/learnobsidian/0808/

Vercel

vercel.com ↗
03

选择最顺手的入口
可以直接导入项目，也可以连接 GitHub 仓库。

确认项目设置
静态 HTML 通常无需复杂配置，按默认选项继续即可。

点击 Deploy
等待部署完成，拿到 vercel.app 公开网址。

进阶时再用 CLI
以后也可以安装 Vercel CLI，让 Agent 帮你完成部署操作。

好处：既能连接 GitHub 自动更新，也适合管理多个网站并查看项目数据。
Quick decision

别纠结工具。
按你现在的需求选。

今天就想发出去

选 Netlify

把文件夹拖进去，拿链接。先完成第一次发布最重要。

准备持续更新

选 GitHub Pages

代码和网站放在一起，修改记录清楚，push 后自动更新。

以后要做更多网站

选 Vercel

和 GitHub 配合顺手，也方便管理多个前端项目。
